## 📖 序文：伝説のアンプを録音する芸術

1970年代後半から1980年代初頭の伝説的なスタジオセッションにおいて、エレキギターのマイキングは単一のマイクをアンプの前に置くだけのものではなくなりました。当時の名エンジニアたちは、**無垢材（Hardwood）キャビネットの響き**、**大出力ドライバーによる濁りのない忠実度**、そして**完全な位相整合（Phase Alignment）によるデュアルマイキング**の相乗効果こそが、スピーカーから飛び出す巨大で立体的なギターサウンドの真の秘密であることを発見しました。

**TattooYou**に搭載された**1x12 Hardwood Cab Lab**は、このスタジオ環境を精密に再現します。

## 🔊 1. EVM-12LドライバーとHardwoodキャビネットの音響物理

### A. スピーカー歪みゼロ（Zero Speaker Breakup）と無限のヘッドルーム
伝統的なギター用スピーカー（25W〜30Wのペーパーコーン）は、パワーを入れるとコーン紙自体が歪み、高域に粗いサチュレーションを生み出し、低域を圧縮します。

**EVM-12L**（200W〜300W定格、7.5kgの大型セラミックマグネット、アルミダイキャストフレーム）は、それとは正反対の設計思想で作られています：
* **純粋な真空管ダイナミクス：** スピーカーコーン自体が音を濁らせません。耳にする倍音とサチュレーションは、**6L6真空管と'78 Mark Iプリアンプ回路そのものの純粋なサウンド**です。
* **抜群の弦分離感：** 複雑なコードワークやキース・リチャーズ特有のオープンGチューニングでも、すべての弦の音が混ざり合わずにクリアに響きます。

### B. バスレフポート付き無垢材（Hardwood）キャビネット
一般的なオープンバックのコンボキャビネットとは異なり、チューニングされた前面バスレフポートを備えた無垢材キャビネットを採用：
* **タイトで正確な低域：** **80 Hz〜160 Hz**のエネルギーをタイトに引き締め、ブーミーな低音の濁りを徹底的に排除します。

## 🎯 2. マイキング・マトリックス

```text
                  ┌──────────────────────────────────────────────┐
                  │                 スピーカーコーン               │
                  │                                              │
                  │      ( -3 )      ( -2 )      ( -1 )   ( 0 )  │
                  │      外周        コーン面   キャップエッジ  センター│
                  │     (Dark)       (Warm)     (Sweet)   (Bright)│
                  │                                              │
                  │  [ PORT ]  <─── (バスレフポート)              │
                  └──────────────────────────────────────────────┘
```

* **`0: Direct`（センター）:** 鋭いピッキングアタックと輝くような高域（4 kHz〜8 kHz強調）。
* **`+1: Edge`（キャップエッジ）:** 抜けの良いクラシックロックのリズムバイト。
* **`-1: Sweet`（スイートスポット）:** **スタジオ基準の黄金バランス。** あらゆるジャンルに対応する推奨初期設定。
* **`-2: Warm`（コーン面）:** 滑らかな高域と丸みのある中域。ブライトなシングルコイルに最適。
* **`-3: Dark`（外周）:** 太くダークなウォームトーン。
* **`Port: Bass`（バスレフ）:** 80 Hz〜160 Hzの胸に響く4x12スタイルの重低音パンチ。
* **`Room 3D`（スタジオ空間）:** 自然な反射音と空気感をもたらすステレオペア。

## 🤯 3. 1トラックで完結するワイドステレオ（トラック複製の省略）

### ❌ 従来の手法（DAWトラックの複製とフェイズの崩壊）
従来、ステレオ感を出すためにはトラックを複製してディレイをかけたり、疑似ステレオプラグインを使う必要があり、モノラル再生時に音が消える位相問題（コムフィルター）が発生していました。

### ✅ TattooYouの `STEREO SPREAD 3D`
DAW上で**1つのステレオトラック**を用意し、**`STEREO SPREAD 3D`** をONにするだけです：
* **Mic 1（左ch）に `57 L (-1) Sweet`**、**Mic 2（右ch）に `57 R (-1) Sweet`** を割り当て、**Blendを50%** に設定。
* スピーカー左右の微細な音響特性の違いを利用し、**トラックを複製することなく、超広大なアナログステレオ空間**が瞬時に完成します。
