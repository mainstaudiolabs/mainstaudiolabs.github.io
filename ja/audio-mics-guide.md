## 🔊 1. EVM-12Lドライバーと無垢材（Hardwood）キャビネット

### A. スピーカー歪みゼロ（Zero Speaker Breakup）と無限のヘッドルーム
伝統的なギター用スピーカー（25W〜30Wのペーパーコーン）は、大出力時にコーン紙自体が歪み、高域に粗いサチュレーションを生み出し、低域のパンチを圧縮してしまいます。

**Electro-Voice EVM-12L**（200W〜300W定格、7.5kgの大型セラミックマグネット、アルミダイキャストフレーム）は、それとは正反対の音響思想で作られています：
* **純粋な真空管ダイナミクス：** スピーカーコーン自体が音を濁らせません。耳にする倍音とサチュレーションは、**6L6真空管と'78 Mark Iプリアンプ回路そのものの純粋なサウンド**です。
* **抜群の弦分離感：** 複雑なコードワークやキース・リチャーズ特有のオープンGチューニングでも、すべての弦の音が混ざり合わずにクリアに響きます。

### B. バスレフポート付き無垢材（Hardwood）キャビネット
一般的なオープンバックのコンボキャビネットとは異なり、チューニングされた前面バスレフポートを備えた無垢材キャビネットを採用：
* **タイトで正確な低域：** **80 Hz〜160 Hz**のエネルギーをタイトに引き締め、ブーミーな低音の濁りを徹底的に排除します。

## 🎯 2. マイキング・マトリックス

12インチのギタースピーカーは均一に音を放射しません。マイクをセンターから外周へ移動させることで、高域が自然にロールオフし、中低域の厚みが増します。

```text
                  ┌──────────────────────────────────────────────┐
                  │                 スピーカーコーン               │
                  │                                              │
                  │      ( -3 )      ( -2 )      ( -1 )   ( 0 )  │
                  │      外周        コーン面   キャップエッジ  センター│
                  │     (Dark)       (Warm)     (Sweet)   (Bright)│
                  │                                              │
                  │  [ PORT ]  <─── (バスレフポート)              │
                  └──────────────────────────────────────────────┘
```

| テイク | 物理位置 | 周波数特性 | サウンドキャラクターと最適な用途 |
| :---: | :--- | :--- | :--- |
| **`0: Direct`** | **センター / Dust Cap** | **4 kHz〜8 kHz**を強力に強調。 | 鋭いピッキングアタックと輝くような高域。密集したミックスを切り裂くソロやファンクに最適。 |
| **`+1: Edge`** | **キャップ外周エッジ** | 抜けの良い高域と滑らかなロールオフ。 | 明瞭なバイト感を持つ王道クラシックロックのリズムトーン。 |
| **`-1: Sweet`** | **キャップとコーンの境界** | 音楽的で黄金のバランス（**Sweet Spot**）。 | **スタジオ基準の王道サウンド：** タイトな低域、太い中域、シルキーな高域。あらゆる演奏の推奨初期設定。 |
| **`-2: Warm`** | **コーン面** | 丸みのある中域、5 kHz以上が滑らか。 | オフアクシスの滑らかさ。テレキャスターやストラトのブリッジPUの耳障りな高域を抑えるのに最適。 |
| **`-3: Dark`** | **外周エッジ** | 深い低域、落ち着いた高域。 | 太くウォームなジャズやスモーキーなブルース、ダウンチューニングに最適。 |
| **`Port: Bass`** | **前面バスレフポート** | **80 Hz〜160 Hz**の重低音ブースト。 | 前面の空気振動を収録。4x12スタックアンプのような胸に響く重低音パンチを追加。 |
| **`Room 3D`** | **スタジオ空間ペア** | 3Dの自然な初期反射音と空気感。 | 空間に設置されたステレオコンデンサーペア。「箱鳴り感のない平坦な音」を解消し、本物の部屋の響きを付加。 |

## 🎧 3. Left（L）テイクとRight（R）テイクの物理的差異

すべてのマイク位置に **`L`（左）** と **`R`（右）** のテイクが収録されています：

### なぜ円形のスピーカーで左右の音が異なるのか？
1. **ボイスコイル・ティンセルリード線の質量：** 端子とコイルを繋ぐ編組線（ティンセルリード）はコーンの片側にハンダ付けされています。この微細な質量差が左右の振動特性に有機的な違いを生み出します。
2. **木目と空気の流れ：** 無垢材の木目密度とポート内の気流により、高品位スタジオマイクだけが捉えられる微細な音響の非対称性が生まれます。

## 🔬 4. 位相科学：コムフィルター（音の打ち消し合い）の完全排除

### A. 実機スタジオでの位相の罠
実機のアンプの前に2本のマイクを立てる際、距離がわずか1〜2ミリずれるだけで音の到達時間にズレが生じます：
* その時間差に一致する周波数が逆位相（180度）となり、**互いに打ち消し合ってしまいます**。
* **その結果：** 低域が完全に消え、薄っぺらく鼻づまりのような「缶詰の音」になります。

### B. TattooYouのサンプル精度位相整合
TattooYouでは、すべてのIRテイクに**最小位相変換（Minimum Phase Transform）**を適用しています：
1. すべてのマイク収録波形が**サンプル0（$t = 0$）で正確にスタート**します。
2. **正の位相相関（$> +0.92$）：** 80 Hz〜3 kHzの基音帯域はほぼ$+1.0$で同位相です。**低域が打ち消されることなく、パンチとなって加算されます**。
3. **高域の自然な質感（> 4 kHz）：** 超高域の微細な位相差がアナログ的なスムージングとして機能し、耳障りなピークを自然に整えます。

## 🎛️ 5. DSPアーキテクチャ：並列デュアル・コンボリューション

TattooYouは単一の静的IRに縛られることなく、2系統のゼロレイテンシー・コンボリューションエンジン（`cab1Convolution` / `cab2Convolution`）を等電力カーブで駆動します：

```text
                                  プリアンプ＆6L6パワーアンプ信号
                                                │
                       ┌────────────────────────┴────────────────────────┐
                       ▼                                                 ▼
             [ コンボリューション MIC 1 ]                      [ コンボリューション MIC 2 ]
             テイク：57 L (-1) Sweet                            テイク：87 L (0) Direct (または 57 R)
             フェーダー：-24 dB〜+6 dB                          フェーダー：-24 dB〜+6 dB
             音量比率：w1                                       位相：通常 / 反転（Ø）
                       │                                       音量比率：w2
                       │                                                 │
                       └────────────────────────┬────────────────────────┘
                                                ▼
                                    CAB LAB マスターセクション
                                 （等電力 CAB BLEND コントロール）
                                                │
                        ┌───────────────────────┴───────────────────────┐
                        ▼                                               ▼
               MONO SUM モード                                STEREO SPREAD 3D モード
          センター加算合成：                                     左チャンネル ＝ Mic 1 * (w1 * √2)
          Out ＝ (Mic1 * w1) ＋ (Mic2 * w2)                      右チャンネル ＝ Mic 2 * (w2 * √2)
```

## ⚖️ 6. MONO SUM vs STEREO SPREAD：用途に応じた使い分け

---

### A. MONO SUM（ステレオ・スプレッド OFF）
両方のマイクが信号を処理し、トラックのセンターに加算されます。

* **同一マイクのL＋R加算による高域スムージング（コーン・アベレージング）：**
  * Mic 1: `57 L (-1) Sweet` ＋ Mic 2: `57 R (-1) Sweet`（**Blend 50%**）
  * **効果：** 左右の微細な共振ピークが互いを補い合い、イコライザーを使わずに耳障りな高域のトゲを丸め、太く有機的な中域を作り出します。
* **ダイナミック＋コンデンサーの黄金ブレンド：**
  * **70% Mic 1（57 Sweet）＋ 30% Mic 2（87 Direct）：** 57の噛みつくアタックと、87の深い低域と空気感が融合。
* **重低音の注入（57 Sweet ＋ BassPort）：**
  * ピッキングの輪郭を保ちながら、4x12キャビネット級の低音の重みをプラス。

---

### B. STEREO SPREAD 3D（ステレオ・スプレッド ON）
Mic 1が左チャンネル、Mic 2が右チャンネルに**+3 dB（$\sqrt{2}$）の自動音量補正**を伴って出力されます。

#### 🚀 1トラックで完結するステレオ録音の秘密（トラック複製の省略）
* **DAWのトラックを複製する必要がありません：** 2本のトラックを録音したり、タイミングをずらしたり、疑似ステレオプラグインを挟む手間がゼロになります。
* **本物のアナログ3D空間：** 同じキャビネットの左右の音響差を両耳に届けることで、脳が「目の前に本物のアンプがある空間」を立体的に認識します。

#### ステレオモードでのブレンド活用法：
1. **ウルトラワイド・ダブルトラッキング：**
   * Mic 1: `57 L (-1) Sweet`（左耳） ＋ Mic 2: `57 R (-1) Sweet`（右耳）、**Blend 50%**。1トラックだけで圧倒的なステレオギターの壁が完成。
2. **スタジオ・ライブルーム3D：**
   * Mic 1: `57 L (-1) Sweet`（前面ダイレクト） ＋ Mic 2: `87 Room L 3D`（空間のアンビエンス）、**Blend 25%〜30%**。
3. **ヘッドホン演奏時の疲労軽減：**
   * 頭の中心で鳴るモノラル特有の聴覚疲労を解消し、長時間の演奏やミックスでも耳が疲れません。
